# 💸 Трекер расходов

Небольшое одностраничное приложение, чтобы вести учёт личных расходов.
Всё помещается в один `index.html`, без сборки и без зависимостей — просто открываешь в браузере и пользуешься.

## Как запустить

Самый простой способ — открыть `index.html` двойным кликом в любом современном браузере.

Если хочется через git:

```bash
git clone <ссылка-на-репозиторий>
cd <имя-репозитория>
После этого тот же самый файл уже лежит у вас локально.
```

Что умеет:
Добавлять, редактировать и удалять расходы: описание, сумма, категория, дата, теги, комментарий, валюта.
Свой набор категорий плюс готовые варианты на выбор.
Месячный бюджет с прогресс-баром. Если потрачено больше 80%, появляется предупреждение.
Регулярные расходы: шаблон, который автоматически добавляется раз в день / неделю / месяц.
Фильтры по категории, тегам, периоду и важности, а также обычный текстовый поиск.
Сортировка по дате, сумме, категории или «важные сверху».
Статистика: всего, среднее, максимум, минимум, за сегодня / неделю / месяц.
Диаграммы: столбчатая, круговая и тренд по дням — всё рисуется на Canvas.
Сохранение в localStorage, экспорт и импорт в JSON, выгрузка в CSV.
Тёмная и светлая тема, адаптив под телефон, небольшие анимации и уведомлений при действиях.
Как устроен
HTML5 для разметки.
Чистый CSS: переменные для тем, flexbox, адаптив через медиазапросы.
Vanilla JS на ES6: всё в одном IIFE, данные живут в localStorage, графики — на Canvas.
Никаких фреймворков и npm-пакетов.
Про данные
Всё хранится локально в браузере, на сервер ничего не уходит. Значения лежат в localStorage:

expenseTrackerData — сами расходы
expenseTrackerBudget — месячный бюджет
expenseTrackerCategories — категории
expenseTrackerCurrency — валюта
expenseTrackerRegulars — регулярные расходы
expenseTrackerTheme — выбранная тема
Если нужно перенести данные на другой компьютер, воспользуйтесь экспортом в JSON и импортом на новой машине.

Формат JSON примерно такой:
```
json
{
  "expenses": [
    {
      "id": "abc123x",
      "description": "Кофе",
      "amount": 250,
      "category": "Еда",
      "date": "2026-01-15",
      "important": true,
      "tags": "работа, дом",
      "comment": "утро",
      "currency": "₽"
    }
  ],
  "budget": 30000,
  "categories": ["Еда", "Транспорт", "Жильё"],
  "regulars": [
    { "id": "r1", "name": "Абон. интернет", "amount": 500, "category": "Жильё", "period": "monthly", "lastAdded": "2026-01-01" }
  ]
}
```
CSV выгружается с колонками: Дата, Категория, Описание, Сумма, Важность, Теги, Комментарий.
